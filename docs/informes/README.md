# Informes históricos y documentación vigente

Los PDF del Informe de Avance I y los textos de sus secciones editables/revisadas registran entregas anteriores. Se conservan como evidencia histórica, sin cambiar sus resultados, fechas o afirmaciones como si se hubieran medido nuevamente.

El proyecto actual tiene Caso 1 PIR, Caso 2 CSI con router y Caso 3 conjunto. La pantalla PIR USB fue retirada. El inicio habitual se realiza con un comando que prepara las dependencias y servicios.

Para ejecutar o explicar la versión vigente, consultar [arranque](../arranque.md), [guía completa de la muestra](../guia-completa-muestra.md) y [prueba conjunta](../prueba-conjunta.md). Las versiones Word y PDF vigentes de la guía se generan en `output/documents/` y `output/pdf/`.
